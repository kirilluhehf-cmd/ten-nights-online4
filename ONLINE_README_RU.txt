TEN NIGHTS IN A HOTEL 10.2 — ONLINE + ПЛАВНАЯ СЛОЖНОСТЬ

Запуск на Render:
- Root Directory: пусто
- Build Command: npm install
- Start Command: npm start

Игроки открывают один и тот же URL. По умолчанию оба входят в комнату HOTEL.
Для другой комнаты можно добавить ?room=КОД к URL, например ?room=TEST.

Роли:
- Первый игрок в комнате — host (ведущий, отправляет состояние игры).
- Второй — guest (получает состояние монстров/ночи).
- Не более двух игроков на комнату.

Плавная сложность:
- общий множитель сложности растёт на 10% за каждую следующую ночь;
- скорость появления малыша меняется плавно;
- коэффициент easeFactor также растёт постепенно.

Важно:
Это экспериментальная синхронизация. Она передаёт ключевые состояния ночи и монстров от ведущего, но не гарантирует полного совпадения всех анимаций, звуков и таймеров. Проверяйте игру вдвоём; если обнаружатся рассинхронизации, потребуется доработка конкретных механик.
